# results/

Every number in the report comes from files in this folder. They are generated by code and committed via PRs.

```
results/
├── runs/<experiment>/<run_name>/seed<k>/
│   ├── eval_<eval_name>.json   # metrics + full config + git commit (schema below)
│   ├── preds_<eval_name>.npz   # probs [N,10] float16, y_true [N], orig_index [N]
│   ├── train_log.csv           # per-epoch log (deep models)
│   └── train_summary.json      # deep models: train_time_s, peak_mem_gb, best epoch (read by evaluate.py)
├── optuna/<study>.db           # Optuna studies (sqlite)
├── tables/                     # generated by scripts/aggregate_results.py, do not edit by hand
└── figures/<experiment>/       # generated by analysis code (PDF + PNG)
```

`eval_name` values: `val`, `test`, `test_tta8`, `test_rot<DDD>` (e.g. `test_rot045`), `test_<corruption>_s<S>`
(e.g. `test_blur_s2`), `sdss`.

## `eval_*.json` schema (PROJECT_PLAN §4.4)
```json
{
  "experiment": "e1_orientation", "run_name": "resnet50_rotflip", "seed": 0,
  "model": "resnet50", "eval_name": "test_tta8", "split": "test", "split_version": "v1",
  "git_commit": "abc1234", "timestamp": "2026-12-01T12:00:00",
  "config": {},
  "metrics": {
    "accuracy": 0.0, "macro_f1": 0.0, "balanced_accuracy": 0.0,
    "per_class_recall": [], "per_class_precision": [], "per_class_f1": [],
    "confusion_matrix": [], "n_samples": 0
  },
  "extra": {"rotation_deg": null, "corruption": null, "severity": null, "tta": null,
            "n_params": null, "train_time_s": null, "peak_mem_gb": null,
            "best_epoch": null, "epochs_trained": null}
}
```
Classical models write exactly the same schema (`model` = `logreg` | `svm_rbf` | `xgboost`).

## Writing and reading results (`galaxy.evaluation`, #5)
```python
from galaxy.evaluation.metrics import compute_metrics
from galaxy.evaluation.results import run_dir, save_eval, load_evals, load_preds, eval_name_for

d = run_dir("baselines_classical", "xgboost", seed)             # results/runs/baselines_classical/xgboost/seed0
save_eval(d, "test", compute_metrics(y_true, probs), probs, y_true, orig_index, config, extra={...})
df = load_evals()                                               # one row per eval_*.json under results/runs/
```
* `save_eval` needs only numpy (no torch). `experiment` / `run_name` / `seed` are taken from the folder name
  `<experiment>/<run_name>/seed<k>` (falling back to the same keys in `config`), `model` from `config["model"]`
  (a string, or `{"name": ...}` for deep configs) and `split` from the prefix of `eval_name`.
* Missing `extra` keys of the schema above are filled with `null`, so every file has the same keys.
* Metrics: per-class arrays always have 10 entries in class-index order. `macro_f1` averages over the classes present
  in `y_true` or the predictions and `balanced_accuracy` over the classes present in `y_true` (same as sklearn); on
  the full val/test sets all 10 classes are present.
* `load_evals()` columns: the identifiers, `accuracy`, `macro_f1`, `balanced_accuracy`, `n_samples`,
  `recall_<Class>` / `precision_<Class>` / `f1_<Class>` (short class names, e.g. `recall_Cigar`), `confusion_matrix`,
  every `extra` key, `config` and `path`.
* Deep models: `galaxy.evaluation.predict.evaluate(model, loader, preprocess, run_dir, eval_name, config, ...)` does
  predict → metrics → `save_eval`; `scripts/evaluate.py --run-dir <run> --eval test` re-evaluates a run from its
  `best.pt`. Use `eval_name_for(...)` to build names, so `test_rot045` / `test_blur_s2` / `test_tta8` stay consistent.

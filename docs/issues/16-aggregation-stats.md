## Goal
Every table and figure in the report is generated by code from `results/runs/`, with honest uncertainty.

## Context
Plan §3.4 (aggregation + significance), §6 (per-experiment outputs), §10 (definition of done).

## Tasks
- [ ] `scripts/aggregate_results.py`
  - [ ] Read all `eval_*.json` (`load_evals` from #5). Group by (experiment, run_name, eval_name). Report mean ± std over seeds plus n_seeds.
  - [ ] Write `results/tables/<experiment>.csv` and `.md` (formatted as `0.912 ± 0.004`), plus `results/tables/main_table.md`: every model family, standard test eval, acc / macro-F1 / #params / train time.
  - [ ] Per-class recall table per experiment.
  - [ ] A warning when a group has fewer than 3 seeds (deep) or mixed commits/split versions.
- [ ] `galaxy/analysis/stats_tests.py`
  - [ ] `mcnemar(preds_a, preds_b, y)` (exact binomial for small discordant counts)
  - [ ] `paired_bootstrap(probs_a, probs_b, y, metric="macro_f1", n=2000) -> (delta, ci_low, ci_high)`. Seeds are paired by index.
  - [ ] `compare_runs(run_a, run_b)` prints a one-line summary for the report.
- [ ] `galaxy/analysis/plotting.py`: `set_style()` (one matplotlib style for the whole report), `CLASS_COLORS` and `MODEL_COLORS` (fixed per model family, used in every figure), helpers `bar_with_err`, `line_with_band`, `save_fig(path)` (PDF + PNG, 300 dpi).
- [ ] GitHub Action (optional but nice): run aggregation on PRs that touch `results/` and fail on schema errors.
- [ ] `tests/test_aggregation.py` with fake result files.

## Deliverables
Aggregation script, stats tests, plotting style, tests.

## Acceptance criteria
- Running the script on `main` regenerates every table without manual edits.
- Every other owner uses `plotting.set_style()` and `MODEL_COLORS` (checked during PR review).
